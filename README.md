# Formulário de Contato

Uma interface de formulário de contato desenvolvida com HTML5 e CSS3, com foco em organização visual, usabilidade, acessibilidade básica e design responsivo.

O projeto apresenta um formulário simples e intuitivo, permitindo que o usuário preencha seus dados e escreva uma mensagem por meio de uma interface limpa e agradável.

## Preview do Projeto

O formulário possui um layout centralizado, com uma paleta de cores em tons de verde, campos organizados e elementos visuais que proporcionam uma experiência de preenchimento clara.

## Funcionalidades

- Campo para preenchimento do nome.
- Campo de e-mail com validação nativa do navegador.
- Área de texto para escrever mensagens.
- Campos obrigatórios utilizando o atributo `required`.
- Destaque visual nos campos durante a navegação e preenchimento.
- Efeito de interação no botão ao passar o mouse.
- Layout adaptável a diferentes tamanhos de tela.

Observação: Este projeto é uma interface front-end de estudo. O formulário ainda não possui integração com backend ou serviço de envio de mensagens.

## Tecnologias utilizadas

- HTML5: estruturação semântica e organização dos elementos do formulário.
- CSS3: estilização, layout, cores, espaçamentos, efeitos visuais e responsividade.

## Conceitos aplicados

Durante o desenvolvimento, foram praticados conceitos importantes de desenvolvimento front-end:

- Estrutura básica de um documento HTML.
- Uso de `label`, `input` e `textarea`.
- Associação entre rótulos e campos utilizando `for` e `id`.
- Validação nativa de formulários com `required` e `type="email"`.
- Box Model com `box-sizing: border-box`.
- Centralização de elementos utilizando CSS Grid.
- Flexibilidade de layout com `width: 100%` e `max-width`.
- Pseudo-classes `:hover` e `:focus`.
- Transições com `transition`.
- Personalização de bordas, sombras, cores e tipografia.
